# AI-Powered Personal Life Copilot (JARVIS)

An offline AI-powered desktop assistant built with Python to improve productivity through voice interaction, AI assistance, and desktop automation.

## Overview

JARVIS is a personal desktop assistant designed to help users interact with their computer using natural language and voice commands. The project focuses on local AI processing, automation, and privacy.

## Key Features

- Voice-based interaction
- AI-powered question answering
- Desktop application and browser automation
- Python-based assistant interface
- Offline AI integration using Ollama and a compatible local language model
- Text-to-speech responses

## Technology Stack

- **Language:** Python
- **Interface:** PyQt5
- **AI:** Ollama and local language models
- **Voice:** SpeechRecognition, pyttsx3
- **Automation:** PyAutoGUI
- **System Integration:** psutil
- **Packaging:** PyInstaller

## Getting Started

1. Clone or download this repository.
2. Install Python and the dependencies required by the project.
3. Install and configure Ollama if your setup uses a local language model.
4. Run the main Python application file.

Refer to the project source files for the exact setup and execution instructions.

## Project Status

Developed as a personal AI and automation project to explore desktop integration, voice interfaces, and locally run AI systems.
